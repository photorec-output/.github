# PhotoRec - Carve Files from Your Own Disk

## Berth

The disk is yours, and you know why the files vanished: a format, a delete, a lost folder.
You have another disk with room for the recovery. You do not write the results back onto the same drive.
You have stopped using the damaged disk for normal work.
You are not trying to break encryption. If the volume needs a password you do not have, carving will not supply it.

## Tide

A recent delete on a quiet disk has a better chance than a disk you have filled for a week.
A disk that clicks should not be carved for hours. You will make it worse. If the files matter, stop and think about a copy of the disk made by someone who does that work, rather than a long read on a dying drive.
A solid-state drive may have already discarded the cells. A carve can come back empty. That emptiness is an answer.
The more you install and download onto that disk, the less remains.

## Line

Select the disk whose size matches the one in your hand.
Send the output to a different disk.
Start with the file types you actually lost, if the menu allows that, so you are not buried in irrelevant junk.
Let it run, then stop when you have a sample you can open. You do not have to carve the entire disk before you look.

## Fender

Open a handful of recovered files.
If they are your photos or your documents, continue or copy out the ones you recognize.
If they are fragments and garbage, more hours may not help. Note that and stop.
Do not rename the pile by hand before you have seen a real file. You will lose the only grouping the tool gave you.

![PhotoRec writing recovered files to a different disk the owner chose](https://www.cgsecurity.org/mw/images/PhotoRec_src.png)

## Current

Recovered files live on the spare disk.
The source disk is still not your working drive.
A file that opens is a success even if the name is wrong.
A file that does not open is a fragment. Do not build a plan on it.

## Do not sail

Do not point PhotoRec at a disk you do not own.
Do not use it to pull files out of someone else's encrypted backup.
Do not run it as a way to "see what is on" a drive you were asked only to deliver.
Do not install software onto the same disk while it runs.
Do not format the source because the first minute looked empty.

## Return

Stop the carve when you have what you can use or when the results are nonsense.
The source disk can be set aside unplugged.
The good files are copied again to a normal folder with real names.
The junk recovery can be deleted once you are sure you have looked.

## Chart

Which disk.
Where the output went.
Whether real files opened.
Whether you stopped early on purpose.

## Not this harbor

This is not a partition editor. If the disk does not even show volumes, a partition tool is the earlier question, and it still only belongs on your disk.
It is not a photo organizer.
It will not restore file names and folders as they were.
It will not decrypt.
A cloud trash can is a different place. Check that before you carve a drive.

## Next tide

A second pass only if you chose the wrong types or the wrong disk the first time.
The same output disk, a new folder, so you do not mix two guesses.
If the first sample opened, you can let a longer run finish.
If it did not, stop. The backup you should have had is the real lesson, and the carve will not grow one.

## Log

You can name the disk.
You did not write the results onto it.
You opened samples before you trusted the pile.
You did not touch a drive that was not yours.

## Harbor master

A customer's disk gets this only with their say-so and a spare disk for the output.
A laptop you were lent is not a carve.
If two disks look alike, unplug the one you are not recovering.
Uninstall does not delete the recovered files. They are on the spare disk you chose.
